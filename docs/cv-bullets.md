# MRT analytics CV description

**Singapore MRT Demand & Station Operations Analytics**  
Python, pandas, SQL/DuckDB, Power BI, Streamlit, Plotly, GitHub Actions

- Processed 29K+ LTA station-hour records across 187 MRT/LRT station codes over four months using Python; wrote SQL queries to analyse activity by month, hour and day type.
- Built Power BI dashboards and a deployed Streamlit app; extended the app with coverage-aware monthly comparisons and a five-station review shortlist accounting for 10.43% of recorded activity.
- Implemented a GitHub Actions workflow for monthly ingestion and validation; shared comparison logic between the app and CSV exports to exclude missing codes and mismatched hourly coverage from growth calculations.
